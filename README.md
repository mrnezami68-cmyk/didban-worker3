## 🚀 نحوه اتصال به Cloudflare Workers Builds (استقرار خودکار Git CI/CD)

1. در داشبورد کلودفلر به بخش **Workers & Pages** ──► ورکر **`market-ai-interpreter`** بروید.
2. وارد تب **Settings** ──► بخش **Builds** شوید.
3. روی **Connect GitHub repository** کلیک کنید.
4. ریپازیتوری **`mrnezami68-cmyk/didban-worker3`** را انتخاب کرده و شاخه اصلی را روی **`main`** قرار دهید.
5. از این پس، هر `git push` به صورت خودکار و بدون دخالت دست، ورکر را در کمتر از ۱۰ ثانیه Build و Deploy می‌کند.

---

## 🔒 نحوه تنظیم Secret در کلودفلر (OPENROUTER_API_KEY)

جهت حفظ بالاترین استانداردهای امنیتی، کلید OpenRouter هرگز در گیت‌هاب قرار نمی‌گیرد:
1. در داشبورد کلودفلر ──► ورکر **`market-ai-interpreter`** ──► تب **Settings** ──► **Variables and Secrets**.
2. در بخش **Secrets** روی دکمه **Add** کلیک کنید:
   * نام سکرت: **`OPENROUTER_API_KEY`**
   * مقدار: کلید اختصاصی شما از OpenRouter (`sk-or-v1-...`)
3. دکمه **Deploy / Save** را بزنید.

## 📡 اندپوینت‌های ورکر ۳ (REST Endpoints)

| مسیر | متد | شرح عملکرد |
|---|---|---|
| `/` | `GET` | ریشه ورکر، شناسنامه سرویس و مستندات |
| `/api/health` | `GET` | استعلام وضعیت سلامت ورکر، اتصالات D1 و درگاه‌های AI |
| `/api/ai/chat` | `POST` | چت زنده تحلیلی مشاور هوشمند با سد ضدسیگنال و داده‌های زنده |
| `/api/ai/interpret` | `POST` | تولید گزارش‌های ۳ لایه‌ای روایی بازار با مدارشکن دوگانه |
| `/api/ai/validate` | `POST` | اعتبارسنجی ضدتوهم عددی متون نسبت به شواهد رسمی |
